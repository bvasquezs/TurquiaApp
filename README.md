## 🚀 Funcionalidades y Requisitos de la Pauta Implementados
* **Diseño Visual con Material 3**: Interfaz colorida y adaptada para niños utilizando componentes estructurados y accesibles[cite: 1].
* **Formularios Validados**: Módulos de práctica y registro con validación reactiva desde el `ViewModel` y mensajes visuales de error[cite: 1, 22].
* **Navegación Funcional**: Flujo estructurado mediante `NavHost`, `NavController` y menús interactivos (`NavigationBar` / `ModalNavigationDrawer`)[cite: 4, 43].
* **Gestión de Estado y Persistencia Local**: Uso de `DataStore Preferences` para guardar configuraciones de usuario de forma local[cite: 65].
* **Recursos Nativos**: Integración de la **Cámara y Galería** para personalizar el avatar del perfil del usuario mediante `ActivityResultContracts`[cite: 2, 13].
* **Animaciones**: Transiciones fluidas y feedback visual interactivo con `AnimatedVisibility` y cambios de color animados[cite: 65].
